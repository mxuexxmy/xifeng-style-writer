# Examples

这份文件是教学样稿，不是原文摘录。本 skill 不依赖任何外部原文库；风格校准以本文件与同目录规则为准。

用途：校准「像不像」。不要背句子，对照节奏、转角和机制深度。

## 用法

1. `writing-mode` 或用户要求「特别像」时，在读完 [style-map.md](style-map.md) 后读本文件
2. 起草前先扫一遍正例的推进链
3. 定稿前用偏味清单自查，再回 [taboo-list.md](taboo-list.md)

## 同一题目

## 正例

### 标题

别急着骂「内卷」，你先看懂谁在买你的稳定幻觉

### 正文

最近又有人留言：公司天天讲拥抱变化，结果加班更多了，心里更慌了。

很多人第一反应是：领导画饼，员工遭罪。

这么理解不能说全错，但只说到了皮毛。

你如果只看到这一层，就会误判。

说白了，很多公司卖的不是「稳定工作」，卖的是「你愿意把稳定感交出去」这件事本身。

你想想，组织真正稀缺的是什么？不是口号里的创新，而是在不确定里还能继续运转的人。稳定岗位听起来像福利，更像旧周期留下来的定价方式。周期一紧，定价先改：口号升级成「拥抱变化」，成本却还是落在执行层。

谁在得利？需要弹性用工、却不想公开改契约的一方。谁在承担成本？把「听话」和「熬年限」当成长期筹码的人。结构会持续复制，因为对组织来说，这比重建一套真保障更便宜。

我给你举个例子。同一间办公室，两个同事：一个把全部安全感押在岗位头衔上，一个把时间分给可迁移的本事和现金流备选。外面一晃，前者先慌，后者至少还有第二方案。不是性格差异，是位置差异。

真正稀缺的不是一句「别焦虑」。真正稀缺的是：你能不能在口号变来变去时，先保住自己的选择权，再谈升级。

### 旁注：为什么像

1. 钩子来自留言，口语入题，不铺长背景
2. 先摆表层理解，再明确转角
3. 中段拆「谁得利 / 谁付成本 / 为何持续复制」
4. 例子具体，用来推位置判断，不是热闹点缀
5. 结尾压成规则：保选择权，而不是情绪动员

## 偏味对照

### 标题

面对变化，我们都要更努力一点点

### 正文

现如今，社会节奏越来越快。很多人都感到焦虑，这很正常。你想想，说白了，内卷确实不好。但请相信自己，只要坚持学习、保持乐观，拥抱变化，终会收获属于自己的曙光。公司有公司的难处，员工也有员工的不易，我们要互相理解。与其抱怨，不如行动起来，做一个更好的自己。

### 旁注：为什么不像

1. 只有口头禅（你想想、说白了），没有机制拆解 → 见 taboo「只学口头禅」
2. 结尾落到加油式鸡汤 → 见 taboo「鸡汤版」
3. 用「我们」集体发言，正确废话多 → 见 taboo「社论版」
4. 没有位置、激励、旧答案失效，态度满、判断空

### 偏味速查

如果你写出的稿子更像上面这篇，优先改这四件事：

- 删掉动员句，换成一条冷规则
- 补「谁得利 / 谁承担」
- 用一个具体场景替换抽象鼓励
- 把「我们」改回「你 / 我」的位置判断
