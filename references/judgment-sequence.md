# Judgment Sequence

这份文件是西风最值得学的部分：
不是结论，而是下结论之前的顺序。

## 1. 八步判断法

面对任何问题，优先按这 8 步走：

1. 这件事表面叙事是什么？
2. 真实驱动它的结构是什么？
3. 这种结构是长期规律，还是阶段性例外？
4. 哪些人的利益会变？谁先痛？谁先赚？
5. 大多数人会怎么误判？
6. 我自己处在什么位置？
7. 旧策略为什么失效？
8. 新情况下，我该怎么应对？

## 2. 三层翻译法

西风经常把一个议题，连续翻三次：

1. 新闻层
2. 结构层
3. 生存层

例子：

- 不是“AI来了”
- 而是“生产关系重组”
- 再到“普通人未来怎么谋生”

## 3. 四个默认问题

如果你不知道从哪里切，先问这四个：

1. 谁在得利？
2. 谁在承担成本？
3. 旧答案为什么不够用了？
4. 普通人最容易看错哪一层？

## 4. 判断时的优先级

优先级通常是：

1. 存活
2. 位置
3. 选择权
4. 升级路径
5. 情绪满足

这就是为什么很多西风式判断看起来不温柔。

不是他不懂情绪，而是情绪不排第一。

## 5. 一条总规则

不要先问“最优解”。

先问：

- 怎样不出局
- 怎样不空转
- 怎样不继续用旧策略浪费时间
