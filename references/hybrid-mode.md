# Hybrid Mode

这份文件定义 `hybrid-mode`：在西风骨架上，加入「传播入口 + 专业承接」。

它是一套**自包含的折中写法**，不依赖任何外部作者资料库或私人原文。

旧触发词 `Link x 西风` 视为本模式的别名，按本文件执行。

## 1. 什么时候用

适合：

- 既要能传开，又要能落地
- 既像观点文，又能自然接到咨询、服务或下一步行动
- 用户说：中和一下、传播+转化、Link x 西风、既锐利又专业

不适合：

- 只要纯西风判断、不要任何承接
- 只要行业报告、白皮书、合规文书
- 只要情绪宣泄或纯鸡汤

拿不准时：默认用 `writing-mode`；只有用户明确要「传播+承接」才进 hybrid。

## 2. 双层目标

| 层 | 负责什么 | 不能丢掉什么 |
|----|----------|--------------|
| 西风骨架 | 拆表层、找结构、看位置、判旧答案失效 | 判断感、转角、冷规则 |
| 传播承接 | 开头告诉读者为何值得看；中后段给边界与下一步 | 可读性、可执行、不硬推销 |

一句话：

`西风负责把局拆清楚，承接层负责让人知道这跟自己有关、接下来能做什么。`

## 3. 默认结构

1. **价值入口**（传播层）
   - 一上来回答：这件事为什么现在值得看
   - 点出读者的真实痛点或误判，不铺长背景
2. **表层理解**（西风）
   - 先讲大多数人会怎么看
3. **转角**（西风）
   - 明确：只看到那一层会误判
4. **机制展开**（西风）
   - 谁得利、谁承担、旧答案为何失效、位置怎么重排
5. **专业落地**（承接层）
   - 适合谁 / 不适合谁
   - 工具或方法的边界是什么
   - 普通人可执行的一小步是什么
6. **冷结论 + 轻承接**（两者交汇）
   - 先给一句硬判断
   - 再自然接到进一步交流、诊断或咨询
   - 不要写成销售话术收尾

## 4. 语气控制

保留：

- 第一人称
- 结构感、位置感
- 对读者说话，而不是对空演讲

放宽（相对纯西风）：

- 冷度略降：仍锋利，但不故意把人推远
- 专业词可以出现，但出现后立刻翻译成人话
- 可以给「下一步」，但不能变成催单

禁止：

- 丢掉机制，只剩顾问口吻
- 结尾强推、恐吓式转化
- 堆黑话装专业
- 写成行业报告或社论

## 5. 与纯 writing-mode 的差别

| | writing-mode | hybrid-mode |
|---|--------------|-------------|
| 主目标 | 把判断讲透 | 判断讲透 + 能承接 |
| 开头 | 钩子即可 | 钩子必须带「为何值得看」 |
| 中段 | 机制为主 | 机制为主，并补适合/不适合/边界 |
| 结尾 | 冷规则 | 冷规则 + 轻量下一步 |
| 温度 | 更冷 | 略暖，仍不鸡汤 |

## 6. 最低合格标准

一篇 hybrid 稿至少要同时满足：

1. 有清晰转角和机制拆解（否则不像西风）
2. 有「适合谁 / 不适合谁」或等价边界（否则没有专业承接）
3. 结尾有判断，且承接不生硬（否则要么像评论员，要么像销售）
4. 删掉承接段后，中段判断仍然成立（说明骨架真在，不是包装）

## 7. 回查问题

定稿前问：

1. 读者 30 秒内知不知道「这跟我有关」？
2. 中段有没有把旧答案为何失效讲清？
3. 专业信息有没有翻译成人话？
4. 结尾是在给选择权，还是在逼单？
5. 如果去掉所有承接句，文章还像不像西风？
