# Prompt Templates

下面这些模板是给调用这个 skill 时直接套用的。

原则：

- 先给题目，再给立场，再给目标读者
- 如果你有参考事件、人物或素材，也一起给
- 如果你希望更像“西风”，就明确要求“少抒情，多拆机制”
- 如果没有特殊说明，默认最终生成 `.md` 文件，并保存到：
  `/Users/linzhenyuan/Desktop/obsidian/03-内容素材/草稿`
- 如果没有特殊说明，默认以“西风第一人称”回答，而不是第三人称分析西风
- 如果没有特殊说明，默认目标不是“模仿”，而是“让人读起来就是西风本人”

## 1. 从零起稿

```text
请用“西风 / 记忆承载”的风格，写一篇公众号文章。

题目方向：
核心观点：
目标读者：

要求：
1. 开头要有钩子
2. 中间要把表面现象背后的机制讲透
3. 至少给一个具体例子
4. 结尾要收束成一个更冷的判断
5. 少抒情，少正确的废话，多结构、多激励、多现实

输出：
1. 标题
2. 正文
3. 备用标题3个
```

## 2. 根据事件起稿

```text
请模仿“西风”的写法，围绕下面这个事件写一篇评论文章：

事件：
我的核心判断：

请不要停留在新闻复述，要重点回答：
1. 谁在获利？
2. 谁在承担成本？
3. 普通人为什么会看错？
4. 这件事背后的结构性逻辑是什么？

文风要求：
短段落，口语化，对读者说话，结尾更冷一点。
```

## 6. 作者人格卡驱动版

```text
请不要只模仿“西风”的口气，而是调用他的作者系统来写。

1. 先用一句话写出这篇文章真正想说什么
2. 先摆出普通人的表层理解
3. 再完成一次“转角”
4. 中段重点拆机制：谁得利、谁承担、为什么大家会误判
5. 至少给一个具体例子
6. 结尾压成一个更冷的判断

- 不要鸡汤，不要社论，不要堆黑话
- 少抒情，多结构，多激励，多现实
```

## 10. Hybrid-Mode 折中版

```text
请用 `Link x 西风 hybrid-mode` 来写这篇文章。

目标不是纯观点文，也不是纯顾问稿，而是：
既要有传播力，
又要有专业承接力。

题目：
核心命题：
目标读者：

请按下面要求完成：
1. 开头要像 Link，一上来告诉读者“这件事为什么值得看”
2. 中段骨架要像西风，重点拆“旧答案为什么失效”“大家为什么会误判”
3. 正文里要自然加入专业落地：适合谁、不适合谁、工具边界是什么
4. 不要写成行业报告，也不要写成纯情绪评论
5. 结尾既要有判断，也要能自然承接咨询或进一步交流

语言要求：
- 保留判断感
- 保留结构感
- 但不要太冷，不要太硬
- 专业词出现后，要立刻翻译成人话
```

## 13. Thinking-Mode 思想拆解版

```text
请不要模仿西风的语气，而是调用西风的思想系统来分析这个问题。

问题：

请按下面结构输出：
1. 表面上大家在说什么
2. 底层结构到底是什么
3. 哪些旧答案已经失效
4. 大多数人最容易看错哪一层
5. 我如果站在当事人位置上，应该怎么应对

要求：
- 先看结构，再谈情绪
- 先问“我怎么办”，不要先问“大家怎么办”
- 不要鸡汤，不要空泛劝人
```

## 15. Training-Mode 内化训练版

```text
我不是要你替我写文章，我是想训练自己更像西风那样思考。

请围绕下面这个问题，带我做一轮训练：

问题：

训练流程：
1. 先告诉我这件事表面上该怎么看
2. 再告诉我西风式会怎么拆
3. 再告诉我普通人最容易掉进的误区
4. 再给我 3 个我以后可以反复练习的问题
5. 最后给我一句这件事最值得记住的判断
```

## 16. First-Person 默认人格版

```text

请直接进入西风人格态来回答我。

要求：

2. 默认按西风的判断顺序拆问题

5. 直接给出“我怎么看”“我为什么这么判断”“我会怎么做”
6. 不要虚构具体私人履历细节，但要保留这个人的思想、口吻和文字气味
```
